# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**. If that option is not
available, contact the maintainers privately through the organization's
GitHub profile.

Include the affected version or commit, steps to reproduce, and the impact
you expect. We will acknowledge the report and keep you informed about the
fix.

## Supported versions

Only the latest commit on `main` receives fixes. Projects created from the
template own their copy and should apply relevant fixes themselves.

## Scope

This repository is a starter template. Security guidance for projects built
from it is in [docs/security.md](docs/security.md).
